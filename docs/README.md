# Docs

Project documentation. The main overview lives at the repository root:
[`../README.md`](../README.md).

Files in this directory:

- `STATE.md` — current status, active bugs, roadmap, key commands
- `STATE_history.md` — chronological log, frozen as of each day
- `GLOSSARY.md` — acronyms, terms, and code references
- `OPERATIONS.md` — run/stop/monitor/resume commands and failure modes
- `replays/` — saved replay HTML files used as evidence in pilot diagnostics

---

Start with `STATE.md` if you are new to the project. It contains the
bootstrap path for a fresh session.
